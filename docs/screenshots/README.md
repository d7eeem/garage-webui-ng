# Screenshots

High-resolution UI screenshots used by the project README.
Captured at a 1440x900 viewport with a 2x device scale factor (2880x1800 PNGs),
in the default light theme.

The cluster/bucket/object views were generated against a live Garage cluster
with realistic sample data. `setup-wizard.png`, `settings-users.png` and
`settings-account.png` show the authentication surfaces, which need no cluster;
they use throwaway accounts, and no password field ever holds a value.
